# Preset: Frontend React/TypeScript

## Estrutura vazia inicial

```text
public/
src/
tests/
```

## Decisões da entrevista

- versão do Node e gerenciador de pacotes;
- ferramenta de build e renderização;
- navegadores e dispositivos suportados;
- design system e acessibilidade;
- estado, dados remotos e contratos de API;
- autenticação e autorização;
- tratamento de erros e observabilidade;
- ambiente de publicação;
- comandos de lint, testes unitários, testes de navegador e build.

## Opções a avaliar

- React com TypeScript estrito;
- Vite quando renderização no cliente for suficiente;
- Vitest e Testing Library;
- Playwright para fluxos de navegador;
- ESLint, formatação e análise de dependências.

Não selecionar nem instalar dependências sem registrar a decisão no perfil do projeto.
