# Preset: Backend Python/FastAPI

## Estrutura vazia inicial

```text
src/
tests/
```

## Decisões da entrevista

- versão do Python;
- gerenciador de dependências;
- estilo de API e consumidores;
- persistência e migrações;
- autenticação e autorização;
- integrações externas;
- validação, erros e observabilidade;
- ambiente de execução;
- comandos de lint, tipagem, testes e build.

## Opções a avaliar

- FastAPI e Pydantic;
- pytest e HTTPX para testes;
- Ruff para lint e formatação;
- verificação estática de tipos;
- cobertura de testes e scanner de dependências.

Não selecionar nem instalar dependências sem registrar a decisão no perfil do projeto.
