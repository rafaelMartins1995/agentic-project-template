# Camada canônica de agentes

Esta pasta contém instruções independentes do ambiente de execução.

- `PROTOCOL.md`: contrato de comunicação e handoff.
- `ROUTING.md`: quando usar cada papel.
- `PLUGIN_CATALOG.md`: capacidades obrigatórias e opcionais.
- `profiles/`: responsabilidades e limites dos papéis.
- `presets/`: decisões iniciais para cada tipo de projeto.

Integrações específicas do agente padrão ficam em `.claude/`. Se outro host for adotado no futuro, ele deve apontar para estes arquivos em vez de duplicar as regras do projeto.
