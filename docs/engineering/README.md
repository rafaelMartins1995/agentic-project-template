# Engenharia do projeto

| Camada | Arquivo ou pasta | Pergunta respondida |
|---|---|---|
| Regras permanentes | `AGENTS.md` | Como os agentes trabalham? |
| Contexto | `PROJECT_PROFILE.md` | O que é este projeto e o que deve ser preservado? |
| Agentes | `AGENT_CATALOG.md` | Quais papéis estão ativos e com quais limites? |
| Ferramentas | `TOOLING.md` | O que pode ser usado ou instalado? |
| Estado | `EXECUTION_CHECKLIST.md` | Qual gate está pendente? |
| Especificação | `specs/` | O que será construído e por quê? |
| Plano | `plans/` | Como será implementado e testado? |
| Decisões | `decisions/` | Por que uma decisão importante foi tomada? |
| Evidências | `evidence/` | O que foi realmente executado e observado? |
| Operação | `runbooks/` | Como executar, validar ou recuperar? |

Não duplicar conteúdo entre camadas. Use os arquivos em `templates/` como ponto de partida.
